# Payments Integration

## Выбор провайдера

| Провайдер | Когда использовать | Комиссия | Плюсы | Минусы |
|---|---|---|---|---|
| Telegram Stars | мини-аппы, подписки в TG | ~30% (Apple/Google) | проще всего | дорого |
| ЮKassa | СНГ, рубли, ИП/ООО | 3.5% | надёжно, поддержка | нужен ИП |
| Robokassa | СНГ, рубли, физлица OK | 3–5% | проще оформление | UX похуже |
| Stripe | США/Европа | 2.9% + $0.30 | глобально | в РФ не работает |
| ЮMoney p2p | мелкие чеки между физлицами | 0.5–1% | мгновенно | без чеков |

## Идемпотентность платежей (обязательно)
Каждый запрос на платёж должен иметь `idempotency_key` или `payload` уникальный per-попытка.
Без этого: дубль-нажатие на «Оплатить» = два списания.

```python
# ЮKassa
payment = Payment.create({
    "amount": {"value": "990.00", "currency": "RUB"},
    "description": "Курс по AI",
    "metadata": {"user_id": str(user_id), "course_id": "ai-101"},
}, idempotency_key=f"user_{user_id}_course_ai-101_{attempt}")
```

## Telegram Stars (XTR) — пошагово
1. Создаёшь invoice link через `createInvoiceLink` (Bot API):
```python
url = await bot.create_invoice_link(
    title="Подписка PRO",
    description="30 дней доступа",
    payload="sub_pro_30d_user42",   # уникальный
    currency="XTR",
    prices=[LabeledPrice(label="PRO", amount=100)],   # 100 звёзд
)
```
2. Отправляешь `url` пользователю как кнопку.
3. Бот получает `pre_checkout_query` — ОБЯЗАТЕЛЬНО ответить `answer_pre_checkout_query(ok=True)` за 10 секунд.
4. После успеха — `successful_payment` update. Здесь активируешь продукт.

## Возвраты (refunds)
ЮKassa: API refund по payment_id. Обработать в течение 60 дней.
Telegram Stars: только через техподдержку Telegram — нет API для рефанда.
Stripe: API refund, мгновенно.

ОБЯЗАТЕЛЬНО логируй все refund-операции в свою БД, не доверяй провайдеру как единственному источнику.

## Webhook для оплаты — must have
Не доверяй редиректу пользователя на success-страницу. Активируй продукт только после webhook-подтверждения от провайдера.

ЮKassa webhook events:
• payment.succeeded — деньги пришли
• payment.canceled — пользователь отменил
• refund.succeeded — возврат прошёл

## Чеки 54-ФЗ (РФ обязательно)
Если работаешь с резидентами РФ — нужна онлайн-касса (Атол, Эвотор) или сервис формирования чеков (Atol Online, Bills.ru) с передачей в ОФД.

ЮKassa может пробивать чеки автоматически — настраивается в кабинете.

## Подводные камни
1. Никогда не показывай ключи API на фронте — только на бэке.
2. Webhook должен быть идемпотентным — провайдер может прислать один и тот же event дважды.
3. Сумма в копейках/центах целое число — не дробь.
4. Тестовый режим у каждого свой — не забудь переключить на боевой.
5. ЮKassa в тестовом режиме НЕ принимает реальные карты — только тест-карты из доки.
6. Telegram Stars: 1 star ≈ $0.013, конвертация плавающая. Не привязывай цену в долларах напрямую.
