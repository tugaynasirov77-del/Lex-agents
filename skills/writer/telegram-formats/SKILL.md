# Telegram Post Formats

## Пост-история (конверсия 8–12%)
Структура: Хук (1–2 строки) → Ситуация → Конфликт → Решение → Урок/CTA
Длина: 800–1500 символов
Лучшее время: 9:00–11:00, 19:00–21:00

Пример хука: «Меня кинул партнёр на 500к. Через год я благодарен ему».

## Пост-польза (охват +40%)
Структура: Обещание → Нумерованный список → Усиление → CTA
Длина: 600–1200 символов
Триггеры в заголовке: «5 способов», «3 ошибки», «7 правил», «Чек-лист X».

Правило: каждый пункт списка — одна мысль, не больше двух строк.

## Пост-мнение (вовлечённость x3)
Структура: Провокационный тезис → Аргументы → Контраргумент → Вывод
Длина: 1000–2000 символов
Шаблон входа: «Все говорят X. Но на самом деле...» / «Меня бесит, когда...».

## Продающий пост (конверсия 2–5%)
Структура: Боль → Усиление боли → Решение → Доказательство → Оффер → CTA
Длина: 1500–3000 символов
Правило: CTA не раньше чем через 70% текста. Иначе читатель «закрывается».

## Подборка / список (виралка)
Структура: Заголовок-обещание → Краткое вступление → Список с описанием каждого пункта
Длина: 1000–1800 символов
Триггер: «10 X для Y», «Топ-7 X в 2026».

## Хуки которые работают
• Цифра + результат: «За 3 дня я получил 500 подписчиков»
• Вопрос-провокация: «Почему 90% каналов умирают за месяц?»
• Антитезис: «Все советуют X. Я делал наоборот»
• Конфликт: «Меня кинул партнёр на 500к»
• Сцена: «3 ночи. Я смотрю в монитор и понимаю что слил всё»

## Длина и читаемость
• Абзац максимум 3 строки на мобильном.
• Между абзацами пустая строка.
• Списки маркером • а не цифрами (если не пронумерованный).
• Жирный/курсив выделяй ТОЛЬКО ключевую мысль (1–2 раза за пост).
• В конце поста короткое предложение или вопрос — провоцирует комментарии.

## Лучшее время публикации (СНГ)
Будни: 09:00 / 13:00 / 19:00
Выходные: 11:00 / 15:00 / 20:00
Никогда: ночью с 23:00 до 7:00 (алгоритм роняет охват).

## Запрещённые фразы
«В современном мире», «Не секрет что», «Хочу поделиться», «Как вы знаете»,
«На сегодняшний день», «Стоит отметить, что», «Друзья!» в начале.
