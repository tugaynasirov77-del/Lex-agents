# Funnel & Strategy Frameworks

## AARRR (Pirate Metrics)
Acquisition → Activation → Retention → Revenue → Referral

• Acquisition: откуда узнали (трафик)
• Activation: первое целевое действие (регистрация, первый запуск)
• Retention: возвращаются ли (D1, D7, D30)
• Revenue: платят ли
• Referral: приводят ли других

Анализ воронки: где главный drop-off? Это и есть бутылочное горлышко.

## Lean Canvas (1 страница вместо бизнес-плана)
1. Проблема (топ-3)
2. Сегмент клиентов (early adopters)
3. Уникальное value proposition
4. Решение (топ-3)
5. Каналы привлечения
6. Источники дохода
7. Структура расходов
8. Ключевые метрики
9. Unfair Advantage

Если хоть один блок пустой — гипотеза не готова.

## Jobs To Be Done (JTBD)
Люди не покупают продукт — они «нанимают» его на работу.
Формула: «Когда [ситуация], я хочу [мотивация], чтобы [результат]».

Пример (курс по AI): «Когда я работаю как программист и трачу часы на рутину,
я хочу автоматизировать её через AI, чтобы освободить время на интересные задачи».

Этот JTBD = твой лендинг и весь маркетинг.

## ICE Scoring (приоритизация гипотез)
Каждой гипотезе ставишь оценку 1–10:
• Impact — насколько повлияет если сработает
• Confidence — насколько уверен что сработает
• Ease — насколько легко проверить

Score = (I × C × E) / 3
Делаешь сначала с самым высоким score.

## OKR (цели на квартал)
Objective — качественная цель ("стать №1 в нише вайбкодинга в RU TG")
Key Results — 3–5 измеримых результатов:
  KR1: 50k подписчиков канала
  KR2: 100 продаж курса
  KR3: ER > 6% средний

OKR на квартал, не на год. Если выполнил все KR — цели были слишком лёгкие.

## Blue Ocean (поиск свободной ниши)
1. Перечисли 5 ключевых параметров ниши.
2. Для каждого: что у всех конкурентов одинаково?
3. Что можно убрать / усилить / создать новое?
4. Совмещение этих изменений = твоя дифференциация.
