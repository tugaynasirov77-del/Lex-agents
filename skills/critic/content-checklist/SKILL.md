# Content Quality Checklist

Используй когда проверяешь любой текст: пост в Telegram, продающий лендинг,
скрипт продаж, рекламный креатив, e-mail рассылка.

## Универсальный чек-лист (любой текст)

### 1. Хук — первые 1–2 строки
✓ Конкретная цифра, имя, эмоция, конфликт или сцена
✗ «Сегодня хочу рассказать…», «В современном мире…», «Друзья!»
✗ Длинное приветствие до сути
Если хук не цепляет за 1.5 секунды — переписать. Это решающие 30% успеха.

### 2. Конкретика vs абстракция
✓ «+340 подписчиков за 3 дня», «слил 450к на тестах», «3 ночи без сна»
✗ «хорошие результаты», «много», «эффективно», «значительно»
Каждое размытое утверждение → требуй цифру/имя/срок.

### 3. Логика и связность
✓ Каждый абзац ведёт к следующему — есть нить
✗ Скачки темы, повторы, лишние ответвления
Тест: убери любой абзац — рушится ли смысл? Если нет — резать.

### 4. CTA — ясность целевого действия
✓ Один глагол в повелительном: «Подпишись», «Напиши в личку», «Жми кнопку»
✗ «Будем рады видеть вас среди наших подписчиков»
✗ Несколько CTA в одном тексте — пользователь зависает.
Без CTA текст работает только как имиджевый — отметь это явно.

### 5. Tone of voice
Аудитория → допустимый тон:
• Эксперты, IT, B2B → сдержанный, фактологический
• Предприниматели 30+ → уверенный, прямой, без воды
• Молодёжь 18–25 → дерзкий, провокационный, мемный
• Семейная аудитория → тёплый, поддерживающий
• Премиум → лаконичный, недосказанный

Несоответствие tone — отметь как проблему.

## Запрещённые фразы (моментально топят доверие)
• «В современном мире…»
• «Не секрет что…»
• «Хочу поделиться…»
• «Как вы знаете…»
• «На сегодняшний день…»
• «Стоит отметить, что…»
• «Дорогие друзья!» (если не email)
• «С уважением» (не в письме)
• «Уникальное предложение»
• «Только для вас»

Любая из них = автоматически ❌ СЛАБО + рекомендация заменить.

## Длина и форматирование (Telegram)
• Абзац — максимум 3 строки на мобильном экране
• Между абзацами пустая строка
• Списки маркером • (не цифры если не пронумерованный)
• Жирный/курсив — максимум 1–2 раза за пост (на ключевую мысль)
• Эмодзи — точечно, не в каждом абзаце
• Финальное предложение или вопрос провоцирует комментарии

Норма длины:
• Пост-история: 800–1500 знаков
• Пост-польза: 600–1200
• Пост-мнение: 1000–2000
• Продающий: 1500–3000
Сильно вне диапазона — флажок.

## Продающий текст — отдельный чек

✓ Боль ↔ усиление боли ↔ решение ↔ доказательство ↔ оффер ↔ CTA
✓ CTA не раньше 70% длины — даём прогреться
✓ Социальное доказательство: цифры, отзывы, скриншоты
✓ Гарантия закрывает риск покупателя
✓ Цена обоснована (что входит, что получает клиент)
✗ «Только сегодня скидка 50%» каждую неделю — никто не верит
✗ Скидка без причины — обесценивает продукт
✗ Гипербола без подтверждений («единственный в России»)

## Скрипт продаж — отдельный чек

Структура: Open → Discover need → Present → Handle objections → Close
✓ Открытые вопросы (что/как/почему) > закрытых (да/нет)
✓ Возражение обрабатывается по A.R.P.S. (Acknowledge → Reframe → Prove → Suggest)
✓ Ясный next step в конце ("отправляю КП завтра в 10:00")
✗ Спор с клиентом
✗ Извинения за цену
✗ Слишком быстрая скидка
✗ Игнор возражения и продолжение продажи

## Финальный формат вывода

✅ СИЛЬНО: что работает (1–2 пункта)
❌ СЛАБО: конкретная проблема + как исправить (до 5 пунктов)
ВЕРДИКТ: ПРИНЯТО — если все ❌ закрыты или их нет
ВЕРДИКТ: ДОРАБОТАТЬ — если есть ≥1 критичная проблема

Критичные триггеры ДОРАБОТАТЬ:
• Запрещённая фраза в тексте
• Слабый или отсутствующий хук
• Текст без конкретики (одни абстракции)
• Несоответствие tone аудитории
• Нет CTA где он нужен (продажа/конверсия)
• Длина сильно вне нормы (> 4× границы)
