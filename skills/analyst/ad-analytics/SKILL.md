# Ad Analytics

## Базовые метрики
CPM (Cost per Mille) = затраты / показы × 1000
CPC (Cost per Click) = затраты / клики
CPL (Cost per Lead) = затраты / лиды
CPA (Cost per Action) = затраты / целевое действие (оплаты, регистрации)
ROAS (Return on Ad Spend) = доход / затраты на рекламу
ROI = (доход - затраты) / затраты × 100%

## Юнит-экономика — главное
LTV (Lifetime Value) = средний доход с одного клиента за весь период
CAC (Customer Acquisition Cost) = затраты на привлечение / число клиентов
LTV/CAC = должно быть >= 3. Меньше 3 — бизнес сжигает деньги.

Payback Period = CAC / (среднемесячный доход с клиента)
Норма: < 6 месяцев в инфо, < 12 в SaaS.

## Бенчмарки CPM по площадкам (СНГ, 2026)
• Telegram Ads (официальная): 1.5–4 EUR / 1000
• Telegram посевы (закупка постов): 100–600 ₽ / 1000
• VK Ads: 50–200 ₽ / 1000
• Yandex Direct: 100–300 ₽ / 1000

## Бенчмарки CTR
Telegram пост (нативный): 1–3%
Контекст (Yandex): 5–10%
Ретаргетинг: x2–x3 от холодного

## Атрибуция (главный вопрос: откуда пришёл клиент)
• UTM-метки на КАЖДОЙ ссылке.
• Промо-коды per-канал — самый надёжный способ.
• Self-reported attribution: спрашивай в боте «откуда узнал» — даёт 60–80% точности.
• Last-click attribution встроена в Yandex/Google — но не показывает первое касание.

## Сегментация результатов
Не оценивай рекламу по среднему ROAS. Сегментируй:
• По площадке (TG vs VK vs контекст)
• По креативу (хук А vs хук Б)
• По аудитории (look-alike vs ретаргет vs холод)

Топ-20% креативов дают 80% результата. Остальное — выключай.

## Чек-лист «ROI отрицательный»
1. CTR ниже бенчмарка → плохой креатив или плохая площадка.
2. CPL ОК, но CPA плохой → плохая воронка/прогрев/оффер.
3. CPA ОК, но мало повторных → плохой продукт/onboarding.
4. Всё в норме, но прибыль нет → завышен LTV (рано считаешь).

## Что НЕ делать
• Анализировать кампанию меньше 3 дней.
• Останавливать креатив с малой выборкой (<1000 показов).
• Сравнивать CPM площадок без учёта качества трафика.
• Считать LTV до окончания первого retention-цикла (минимум 30 дней).
