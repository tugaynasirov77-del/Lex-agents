# Telegram Analytics

## Ключевые метрики канала
• Subscribers — общее число подписчиков. Без контекста бесполезно.
• ER (Engagement Rate) = реакций / подписчиков × 100%. Норма 2–8%, ниже 1% — мёртвый.
• ERR (Engagement Rate by Reach) = реакций / охват × 100%. Точнее ER на больших каналах.
• Reach 24h / 48h — охват одного поста за 24/48 часов. Норма 25–60% от подписчиков.
• CPF (Cost Per Follow) — цена подписчика. СНГ инфо: 60–250 ₽, lifestyle: 30–120 ₽.
• Прирост в день — норма для растущего: 0.5–3% от базы. Минус → выгорание.
• Citations Index — индекс цитирования (TGStat). Косвенно показывает авторитет.

## Инструменты
• TGStat (tgstat.ru) — бесплатный обзор любого канала: ER, охват, лучшие посты,
  упоминания, гео-распределение. Платный тариф: динамика по дням.
• Telemetrica (telemetr.io) — аналог, иногда полнее по англоязычным.
• LiveDune — для каналов с подключённой статистикой, более точные ER.
• Insider (insider-tg.com) — мониторинг рекламы конкурентов.

## Как быстро оценить канал по ссылке
1. tgstat.ru/channel/@username — заходишь, смотришь шапку.
2. Проверяешь: ER vs ER похожих каналов (TGStat показывает).
3. «Лучшие посты» вкладка — найдёшь рабочий формат.
4. «Упоминания» — кто рекламирует/где их рекламируют.
5. График подписчиков — нет ли «всплесков накрутки» (резкий +5k за день без постов).

## Признаки накрученного канала
• ER < 0.5% при подписчиках > 5k.
• Reach 24h < 10% подписчиков.
• Резкие приросты без вирального поста.
• Однотипные комментарии («классно», «спасибо») в большинстве постов.
• Большая разница в гео между подписчиками и аудиторией постов.

## Бенчмарки ER по нишам (СНГ, 2026)
• Личный блог эксперта: 6–15%
• Бизнес/маркетинг: 3–8%
• Новости: 2–5%
• Развлекательное/мемы: 4–10%
• B2B/SaaS: 1–4% (низкий ER — норма)
